# VitaPulse — protótipo HTML
Arquivos separados para cada tela do PDF TCC.pdf, com um único styles.css e um app.js compartilhado.

Abra index.html para iniciar.
Fluxos:
- Onboarding → cadastro
- Cadastro/login → página inicial
- Esqueci a senha → código → nova senha
- Página inicial → Performance, Ansiedade, Pressão e Relatório
- Menu ☰ navega entre as telas
- Gráficos são desenhados pelo JavaScript e os botões/controles têm interações demonstrativas.
